## 📚 2. คู่มือการทดลอง 5 ปฏิบัติการเสมือนจริงฉบับสมบูรณ์ (5 Complete Lab Modules)

### 🧪 การทดลองที่ 5.0: แบบจำลองการค้นหาแบบทวิภาค (Binary Search Sandbox)
* **รหัสโมดูล:** `LAB 5.0`
* **รูปแบบการจำลอง:** 2D Slicing Array Canvas $\leftrightarrow$ 3D Binary Search Tree
* **ลิงก์เข้าสู่ห้องปฏิบัติการ:** [https://tsanaphy2023.github.io/computing-science/simulators/chapter05_binary_search.html](https://tsanaphy2023.github.io/computing-science/simulators/chapter05_binary_search.html)

#### 🎯 1. วัตถุประสงค์การทดลอง
1. เปรียบเทียบประสิทธิภาพ Linear Search vs Binary Search
2. พิสูจน์ความซับซ้อนเชิงเวลา $O(\log n)$

#### 📐 2. หลักการและทฤษฎี (Principles & Theory)
Binary Search ทำงานบนข้อมูลที่เรียงลำดับแล้ว โดยลดขนาดช่วงการค้นหาลงครึ่งหนึ่งในทุกๆ ขั้นตอน ทำให้ค้นหาข้อมูล $N = 1,000,000$ ตัวได้ภายในไม่เกิน 20 ครั้ง

#### 🛠️ 3. อุปกรณ์และเครื่องมือจำลองเสมือนจริง
1. 3D Binary Tree Search Node
2. Range Interval Sliders
3. Step Comparison Counter

#### 📝 4. ขั้นตอนการทดลอง (Experimental Procedures)
1. สุ่มข้อมูล 1,000,000 ตัว และเลือกค้นหาค่าเป้าหมาย
2. เปรียบเทียบจำนวนก้าวของ Linear Search และ Binary Search
3. บันทึกผลลงในตาราง

#### 📋 5. ตารางบันทึกผลการทดลอง (Data Collection Table)
| จำนวนข้อมูล $N$ | Linear Search (Max) | Binary Search ($\log_2 N$) | ความเร็วเปรียบเทียบ |
| :---: | :---: | :---: | :---: |
| 1,000 | 1,000 ครั้ง | 10 ครั้ง | 100x เร็วกว่า |
| 1,000,000 | 1,000,000 ครั้ง | 20 ครั้ง | **50,000x เร็วกว่า** |

#### 📊 6. การวิเคราะห์และสรุปผลการทดลอง (Conclusion & Analysis)
* **สรุปผล:** Binary Search เป็นขั้นตอนวิธีค้นหาที่มีประสิทธิภาพสูงสุดสำหรับข้อมูลที่เรียงลำดับแล้ว
