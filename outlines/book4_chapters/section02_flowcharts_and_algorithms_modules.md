# วิทยาการคำนวณ 4 สื่อการเรียนรู้ดิจิทัลและคู่มือปฏิบัติการเสมือนจริงบนระบบ MOOC
## หมวดหมู่ที่ 2 การออกแบบขั้นตอนวิธีและผังงานมาตรฐาน
**ผู้พัฒนาหลักสูตร** ผู้ช่วยศาสตราจารย์ ดร.ชีวะ ทัศนา • สาขาวิชาฟิสิกส์ คณะวิทยาศาสตร์และเทคโนโลยี มหาวิทยาลัยราชภัฏรำไพพรรณี

---

## 🎯 ผลลัพธ์การเรียนรู้ประจำหมวดที่ 2
1. เขียนรหัสลำลอง ตามมาตรฐานสากลที่มีโครงสร้างชัดเจน
2. ออกแบบและวาดผังงาน ตามมาตรฐาน ANSI/ISO ด้วยโครงสร้างควบคุม 3 รูปแบบ
3. ดำเนินการตรวจสอบข้อผิดพลาดของขั้นตอนวิธีด้วยตาราง Trace Table ผ่านเครื่องมือจำลองเสมือนจริง

## 📚 รายละเอียด 5 โมดูลบทเรียนดิจิทัล

### 🔹 โมดูล 2.0 เรื่องเล่าเปิดบทเรียนและภาษาภาพแห่งความคิด
* **เนื้อหาสื่อการสอน** บทเรียนประวัติศาสตร์จากยาน Mars Climate Orbiter กับความจำเป็นของมาตรฐานการสื่อสารขั้นตอนวิธี
* **ชุดจำลองเสมือนจริงในระบบ**
  * Mars Trajectory Unit Conversion Visualizer

---

### 🔹 โมดูล 2.1 การเขียนรหัสลำลองตามหลักสากล
* **เนื้อหาสื่อการสอน** ไวยากรณ์คำสำคัญ `INPUT`, `OUTPUT`, `COMPUTE`, `IF-THEN-ELSE`, `WHILE`, `FOR`
* **ตัวอย่างรหัสลำลอง**
  ```text
  START
    INPUT base, height
    SET area = 0.5 * base * height
    OUTPUT "Area = ", area
  END
  ```
* **ชุดจำลองเสมือนจริงในระบบ**
  * Live Pseudocode-to-AST Syntax Checker

### 🔹 โมดูล 2.2 สัญลักษณ์ผังงานและโครงสร้างแบบเรียงลำดับ
* **เนื้อหาสื่อการสอน** สัญลักษณ์มาตรฐาน Terminator, Process, Input/Output, Flowlines
* **ชุดจำลองเสมือนจริงในระบบ**

### 🔹 โมดูล 2.3 โครงสร้างผังงานแบบทางเลือกและการตัดสินใจ
* **เนื้อหาสื่อการสอน** สัญลักษณ์ Decision (สี่เหลี่ยมข้าวหลามตัด) เงื่อนไขเดี่ยว เงื่อนไขคู่ และเงื่อนไขหลายชั้น
* **กรณีศึกษา** ระบบจำแนกสถานะของสสาร (ของแข็ง ของเหลว ก๊าซ) ตามอุณหภูมิ
* **ชุดจำลองเสมือนจริงในระบบ**
  * Interactive State Decision Simulator

---

### 🔹 โมดูล 2.4 โครงสร้างผังงานแบบวนซ้ำและการตรวจสอบตารางดรายรัน
* **เนื้อหาสื่อการสอน** กลไกการวนซ้ำและการสร้างตารางตรวจสอบค่าตัวแปรทีละบรรทัด (Dry Run)
* **กรณีศึกษา** ขั้นตอนวิธีหา ห.ร.ม. ของยูคลิด (Euclidean Algorithm)
* **ชุดจำลองเสมือนจริงในระบบ**
  * Step-by-Step Animated Trace Table Simulator
* **แบบทดสอบท้ายหมวดที่ 2 (Formative Quiz 5 ข้อ):** ประเมินความแม่นยำในการอ่านผังงานและ Trace Table
